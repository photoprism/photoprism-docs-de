# Externe Speichermedien verwenden

Aufgrund ihrer begrenzten Leistung und Zuverlässigkeit empfehlen wir nicht, herkömmliche SD-Karten, USB-Sticks oder externe USB‑2‑Festplatten zur Speicherung deiner Arbeitsdateien zu verwenden. Für Backups können sie hingegen durchaus geeignet sein.

Externe [Solid-State Drives (SSD)](https://docs.photoprism.app/getting-started/troubleshooting/performance/#storage), die über USB 3 angeschlossen sind, sind in der Regel zuverlässig und schnell genug für deine *originals*-, *database*- und *storage*-Ordner. So kannst du beispielsweise auf einem Computer indexieren, das Laufwerk auswerfen und es dann an einen anderen Computer anschließen, um deine Bilder zu durchstöbern.

Beachte, dass Datenbankdateien in manchen Fällen nicht binärkompatibel sind, zum Beispiel wenn die Version oder die Computerarchitektur nicht übereinstimmt. Sie können außerdem beschädigt werden, wenn du ein externes Laufwerk abziehst, bevor alle Änderungen auf die Festplatte geschrieben wurden. Wir empfehlen daher, regelmäßig [Datenbank-Backups zu erstellen](index.md), damit du deinen Index bei Bedarf wiederherstellen kannst.
